## Featured Projects

### Real-Time Schema Drift Detection — Kafka + Python
**[realtime-streaming-pipeline](https://github.com/houcem58/realtime-streaming-pipeline)**

Stateful micro-batch drift detector for Apache Kafka streams. Detects 5 drift types
(schema rename, type drift, missingness, value, distribution) with F1 = 0.955 average
validated across 4 public datasets (HDFS, NASA HTTP, Online Retail II, Olist).
Precision = 1.0 on HDFS (zero false alarms against real production labels).

`kafka` `python` `drift-detection` `mlops` `docker`

### AML Fraud Detection Platform — GNN + XGBoost + Kafka
**[aml-fraud-detection-platform](https://github.com/houcem58/aml-fraud-detection-platform)**

Anti-money laundering platform combining a 2-layer HybridGAT graph neural network with
XGBoost tabular scoring, a context-aware fusion layer, SHAP explainability, and RLHF
recalibration with automatic rollback. AUC 0.925 ± 0.031 (5-fold account-disjoint
GroupKFold) on IBM AMLSim. Showcase repo — full implementation is private.

`fraud-detection` `graph-neural-network` `xgboost` `apache-kafka` `fintech`
